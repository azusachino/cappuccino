# Material Symbols attribution

The notification icon and the themed (monochrome) launcher icon use the
`cruelty_free` glyph (rounded, filled, 24px) from
[google/material-design-icons](https://github.com/google/material-design-icons),
pulled from `symbols/web/cruelty_free/materialsymbolsrounded/cruelty_free_fill1_24px.svg`
and converted to VectorDrawable path data in
`apps/android/app/src/main/res/drawable/ic_notification.xml` and
`ic_launcher_monochrome.xml`. The path data is unmodified apart from the
viewport transform.
