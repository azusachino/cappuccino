# pi-pocket design attribution

The native reader's visual language adapts design values from
[TannerMidd/pi-pocket](https://github.com/TannerMidd/pi-pocket/blob/ed50991eb9c9b92e717f819073de36633bf83425/web/style.css),
pinned commit `ed50991eb9c9b92e717f819073de36633bf83425`: one monospace face,
surfaces mixed from the palette's foreground over its background, square
tiles, the user prompt row, inline activity timelines and the transcript's
live status line. The owner selected its
[showcase](https://github.com/TannerMidd/pi-pocket/blob/ed50991eb9c9b92e717f819073de36633bf83425/docs/showcase-0.12.1.png)
as the target on 2026-10-12.

pi-pocket is a web app; no JavaScript, CSS, artwork or Omarchy palettes are
copied. Values are reimplemented as Compose tokens. Source license: MIT,
reproduced in `LICENSE` here and bundled in the APK at
`assets/licenses/pi-pocket-LICENSE.txt`.
